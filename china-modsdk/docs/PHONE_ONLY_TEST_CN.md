# 只用一台安卓手机测试 Diorama（无需 Windows）

这份文档是一条**全程在手机上完成**的官方流程。核心结论：**不需要 MCStudio，也不需要 Windows**。

平台明确允许「手动打包发布」；只要 zip 结构符合官方上传规则，就能直接在手机浏览器里上传、机审自测、下载官方测试端、进游戏实测。

---

## 一、先把上传包做好（电脑或手机都行）

如果手边有能跑 Python 的机器（这台构建机上就行）：

```bash
python3 tools/package_upload.py --out dist
```

产物：`dist/Diorama-China-upload-v0.4.0.zip`

它会自动检查官方上传规则，不合格就不生成：

| 规则 | 说明 | 官方错误码 |
|---|---|---|
| zip 根目录**只有**两个文件夹 | `behavior_pack_diorama/` + `resource_pack_diorama/`，不能再套一层父目录 | 10 / 24 |
| 行为包必须有 `entities/` | 机审靠它判定这是行为包 | 24 |
| 资源包必须有 `textures/` | 同理 | 24 |
| `min_engine_version` ≥ `[1,18,0]` | 我们的清单是 `[1,20,0]` | 37 |
| JSON 必须是 UTF-8、无 BOM、可解析 | 脚本逐个校验 | 38 / 40 |
| 不能有 `.MCP` / `.pyc` | 打包时已排除 | 36 |
| 路径必须 ASCII | 已校验 | 16 / 27 |

如果你只能用手机：把构建好的 `Diorama-China-upload-v0.4.0.zip` 传到手机即可，**不要在手机上重新压缩**（手机文件管理器很容易多套一层目录，直接导致错误码 10）。

---

## 二、手机上上传并自测

1. 手机浏览器打开 <https://mcdev.webapp.163.com/#/login>，用开发者账号登录。
2. 进入 **作品管理 → 上架与资源管理 → 手机版 → 发布新资源**。
3. 资源类型选 **add_ons（功能玩法）**；定价选 **免费**（免费可免去上传视频的要求）。
4. 填名称、介绍、适用版本，点「+」上传 `Diorama-China-upload-v0.4.0.zip`。
5. 上传 icon、POS 图、轮播图（手机现做也行）→ **保存**。
6. 回到作品列表，作品处于 **待提交审核** 状态，点条目行尾「…」→ **机审自测**（更严）或 **免机审自测**（更快）。
7. 点页面上方/左下的 **【测试版启动器下载】**，会出现二维码和下载按钮。
   - 同一台手机不能自己扫自己：**直接点下载按钮**，或截图后用微信「扫一扫 → 从相册选取」。
8. 安装官方中国版测试端 APK，用**同一开发者账号**登录。
9. 进 **资源中心 → 找到你的组件 → 下载**。
10. 创建/进入一个世界，在世界的**组件管理**里装载行为包和资源包，进游戏看效果。

> 测试端要求账号下**至少有一个组件处于「审核中」或「自测」状态**，否则会提示「需要账号授权」。

---

## 三、进游戏后检查什么

按顺序看，每一项都对应工程里已经实现的东西：

1. **HUD 小地图**（右上角）：应该出现引擎绘制的真实地形，不是我们预烘焙的图集。
   - 如果这里是图集样式的方块格，说明这个客户端没暴露 `GetMiniMapScreenNodeCls()`，已经自动回退，不报错。
2. **坐标 / 方位 / 群系文字**：走官方 ViewBinder 绑定。
3. **路径点标记**：小地图上应出现路径点图标；添加/删除路径点后标记跟着变。
4. **打开地图界面**（点击 HUD 按钮）：看到贴图地图 + 路径点 + 按钮行。
5. **点「3D」按钮**：切换到 PaperDoll 块几何层。成功后贴图地图被隐藏，显示立体方块模型；失败会自动切回贴图。
6. **雷达**：附近实体应出现标记。

## 四、改完 bug 后重新测试

1. 提升 `behavior_packs/diorama_behavior_pack/manifest.json` 和 `resource_packs/diorama_resource_pack/manifest.json` 里的 `header.version`（例如 `[0,4,0]` → `[0,4,1]`），
   **不升版本会被机审拒绝（错误码 42）**；
2. 重新跑 `python3 tools/package_upload.py --out dist`；
3. 重复第二步。

版本号一致性由测试保证：

```bash
python3 run_tests.py -q
python3 tools/validate.py --strict
```

## 五、明确必须 Windows 的部分

以下能力官方只提供 Windows 客户端，手机无法替代：

- MCStudio 图形编辑器（地图/关卡/UI/特效/预设编辑器）
- 工程级操作（新建工程、UUID 一键随机、导出含编辑信息、`.mep` 导出）
- ModPC 本地开发测试与局域网联机
- PC 调试工具链：IP 连接看日志、断点式日志、性能火焰图

但**这些都不是"把 mod 跑起来"的必需条件**——上面第一到三节已经覆盖了"上传 → 自测 → 装机 → 进游戏"的完整闭环。

## 六、诚实标注

- 「平台允许手动打包」是官方文档原文，已核对；
- 「手机浏览器可完成全部页面操作」是从官方文档 + 平台前端响应式样式推断的，**没有在该账号下实测**；
- 「手动 zip 一定一次过机审」**没有实测**；首次失败请优先核对错误码 10 / 20 / 24 / 37 / 42；
- 本工程的所有 API 调用都已按官方文档与 MCStudio 官方样例对齐，但**尚未在任何真实客户端上运行验证**。
